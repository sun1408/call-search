# 통화 검색

통화 녹음을 휴대폰 안에서 글로 바꾸고, 그 글을 검색하는 설치형 웹앱(PWA)입니다. 무료이고 서버가 없으며, 녹음과 통화 내용은 휴대폰 밖으로 나가지 않습니다.

- 앱 주소: https://sun1408.github.io/call-search/
- 대상: 안드로이드 크롬 (갤럭시에서 시험). 데스크톱 크롬에서도 열립니다.

## 쓰는 법

1. 크롬으로 앱 주소를 열고 메뉴에서 **홈 화면에 추가**(앱 설치)를 누릅니다. 설치한 뒤에는 인터넷 없이도 열립니다.
2. 기록 가져오기
   - **공유**: 내 파일 앱의 `Recordings > TPhoneCallRecords`(에이닷 전화 녹음 폴더)에서 녹음을 길게 눌러 **공유 > 통화 검색**을 고릅니다. 여러 개를 한 번에 골라도 됩니다.
   - **녹음 가져오기** 버튼으로 녹음 파일 여러 개를 고를 수 있습니다.
   - 에이닷에서 복사한 통화 글은 **공유**하거나 **텍스트 추가**로 붙여 넣습니다.
3. 검색창에 낱말을 넣으면 모든 통화 글에서 바로 찾고, 찾은 부분을 형광펜으로 표시합니다. 최신 통화가 먼저 나오고, 상대와 날짜 범위로 좁힐 수 있습니다. 띄어쓰기와 번호의 하이픈은 무시합니다.
4. 기록을 열면 전체 글이 보이고 **복사**, **ChatGPT로 보내기**(공유 화면으로 넘김), **편집**, **삭제**를 할 수 있습니다.
5. **설정**에서 저장 공간, 백업 내보내기와 가져오기(JSON), 모두 지우기를 할 수 있습니다.

## 파일 이름에서 읽는 정보

녹음 파일 이름에서 상대 이름, 전화번호, 통화 시각을 읽습니다. 못 읽으면 파일 날짜를 쓰고, 모두 기록 화면에서 고칠 수 있습니다.

| 앱 | 파일 이름 예 | 시각 |
|---|---|---|
| 에이닷 / T전화 (`TPhoneCallRecords`) | `01012345678_20261020051500.m4a`, `김과장_01012345678_20261020051500.m4a` | UTC로 저장되어 있어 한국 시각으로 바꿔 보여 줍니다 |
| 삼성 전화 | `통화 녹음 홍길동_241015_093012.m4a` | 휴대폰 시각 |
| 기타 | `이름_241015_093012.m4a`, `... 2024-10-15 09-30-12 ...` | 휴대폰 시각 |

## 개인정보와 네트워크

- 통화 기록은 휴대폰 브라우저의 IndexedDB에만 저장합니다. 앱 파일은 Cache Storage에 저장해 오프라인에서도 열립니다.
- 분석 도구, 광고, 외부 글꼴, 외부 스크립트가 없습니다.
- 보안 정책(Content-Security-Policy)의 `connect-src`는 이 사이트 자신과 모델 파일 주소만 허용합니다. 그 밖의 주소로 연결하려 하면 브라우저가 막습니다. 정책은 `src/core/csp.ts` 한 곳에 있고, 빌드가 `index.html`에 넣고 서비스 워커가 HTML과 워커 스크립트 응답 헤더에 붙입니다.

  ```
  connect-src 'self' https://huggingface.co https://*.hf.co
  ```

- 앱이 내려받는 것:

  | 무엇 | 어디서 | 언제 |
  |---|---|---|
  | 앱 파일 (HTML, JS, CSS, 아이콘, 약 100 KB) | `sun1408.github.io/call-search/` | 처음 열 때, 새 버전이 나왔을 때 |

- **ChatGPT로 보내기**는 누를 때만 동작하며, 처음 한 번 안내를 보여 준 뒤 휴대폰의 공유 화면으로 그 통화의 글을 넘깁니다. 거기서 ChatGPT 앱을 고르면 그 글은 OpenAI로 전송됩니다.

## 개발

```sh
bun install            # 개발 도구만 (typescript, fake-indexeddb, playwright-core)
bun test               # 순수 로직 테스트 (검색, 파일 이름, 저장소, 백업)
bun run typecheck
bun run build          # docs/ 에 정적 사이트 생성 (GitHub Pages가 main 브랜치의 docs/ 를 배포)
bun run serve          # http://localhost:8787/call-search/
node scripts/e2e.mjs --suite core [--base https://sun1408.github.io/call-search/]
```

- `src/core/`: 순수 로직 (검색, 파일 이름, IndexedDB 저장소, 백업, CSP)
- `src/app/`: 화면 (바닐라 TypeScript, 프레임워크 없음)
- `src/sw.ts`: 서비스 워커 (앱 셸 캐시, 공유 대상 처리, CSP 헤더)
- `public/`: `index.html`, `manifest.webmanifest`, 아이콘, CSS
- 디자인 원칙: `DESIGN.md`
